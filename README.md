# The Amir Salmani suite

> **Retired 2026-10-17.** This service is decommissioned —
> `amirsalmani.com/suite` and `amirsalmani.com/r` return that site's 404, and
> `npx shadcn@latest add @amirsalmani/*` no longer resolves. See
> [index.md](index.md) and
> [the estate's record](https://github.com/amir-salmani/codebase/blob/dev/offsite/amirsalmani-suite.md).
> What follows described a live service and is kept unchanged.


**121 items across 15 categories, three grounds, no accent hue, MIT.**

The brand tier — tokens, type, layout, the marks — is written here. The
component tier is imported from [ObsidianUI](https://www.obsidianui.dev/) and
re-pointed onto the brand; nothing above the brand tier is authored
([decisions/0019](https://github.com/amir-salmani/codebase/blob/main/decisions/0019-one-source-of-components.md)).

Live at [amirsalmani.com/suite](https://amirsalmani.com/suite/) — a landing, a
catalogue, and a page per item.

**Start at [`index.md`](index.md).** This file exists because GitHub renders a README
and not an index.

`dev` is the default branch. `main` moves when something ships.
[The estate guide](https://github.com/amir-salmani/codebase/blob/main/guide.md)
explains the rest.
